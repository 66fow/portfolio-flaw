I am a dedicated iOS App Developer with 5 years of experience, specializing in mobile application engineering, UI/UX implementation, and low-level system customization.


I focus on building clean, high-performance iOS applications while deeply understanding how mobile software interacts with the operating system. My goal is not just to build standard apps, but to understand runtime internals, debug complex crash logs, and optimize user experience to the finest detail.


Whenever I have spare time, my side interests and hobbies revolve around iOS jailbreaking, tweak development, cheat software research, and game modification. I enjoy experimenting with runtime dynamic hooking, memory injection, binary patching, and custom kernel/tweak configurations.


I have worked on various mobile software projects, including custom iOS overlay tweaks, status bar modifications, and custom mobile application forks. I frequently implement hit-testing, touch pass-through mechanisms, string localization, and custom rendering pipelines.


In game research and modification, I explore binary analysis and memory manipulation, analyzing how executables handle state management, input handling, and rendering engines.


I also manage automation pipelines using GitHub Actions for automated Gradle builds, continuous integration, and releasing compiled artifacts for open-source iOS tools and custom clients.


Some of the tools and technologies I regularly work with include Swift, Objective-C, C/C++, Logos/Theos, Frida, LLDB, Hopper Disassembler, Git, GitHub Actions, Linux terminal environments, and iOS SDKs.


I consider pragmatic problem-solving, self-reliance, and deep curiosity to be my strongest qualities. I thrive when isolating hard-to-trace bugs, memory alignment issues, or stack traces.


Outside of coding, I enjoy exploring music, gaming, and working on hardware/software tinkering experiments.
